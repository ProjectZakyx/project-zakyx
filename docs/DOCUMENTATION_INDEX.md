## 📞 DOCUMENTATION SUPPORT

### **❓ Fragen zur Dokumentation**
- **General Questions**: Create GitHub Issue with label `documentation`
- **API Questions**: Verwende **[API.md](API.md)** oder create GitHub Issue
- **Architecture Questions**: Verwende Architecture-Docs oder create GitHub Issue

### **✏️ Beiträge zur Dokumentation**
- **Corrections**: Pull Request mit Korrektur
- **Additions**: GitHub Issue mit Vorschlag
- **New Documentation**: Diskussion im Team vor Implementation

### **🔄 Dokumentations-Workflow**
1. **Issue erstellen** für neue/geänderte Dokumentation
2. **Draft schreiben** und zur Review stellen
3. **Team-Review** und Feedback einarbeiten
4. **Merge** nach Approval
5. **Index aktualisieren** (diese Datei)
