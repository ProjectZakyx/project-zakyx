# Projekt Ora

Ein Rust-basiertes Desktop-Anwendungsprojekt, das WebView2 für die Benutzeroberfläche verwendet.

## Voraussetzungen

- Rust (neueste stabile Version)
- Windows 10 oder höher
- Microsoft Edge WebView2 Runtime

## Installation

1. Stellen Sie sicher, dass die WebView2 Runtime installiert ist:
   - Besuchen Sie https://developer.microsoft.com/microsoft-edge/webview2/
   - Laden Sie den "Evergreen Bootstrapper" herunter und installieren Sie ihn

2. Klonen Sie das Repository:
   ```bash
   git clone https://github.com/IHR_USERNAME/Projekt-Ora.git
   cd Projekt-Ora
   ```

3. Kompilieren und Starten:
   ```bash
   cargo run
   ```

## Features

- Integration von WebView2 für Web-basierte Benutzeroberflächen
- Moderne Rust-Architektur
- Fehlerbehandlung und Logging
